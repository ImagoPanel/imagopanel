# Support

## Community support

Use [GitHub Issues](https://github.com/ImagoPanel/ImagoPanel/issues) for reproducible bugs and focused feature requests. Use GitHub Discussions for general questions when Discussions are enabled for the repository.

Before opening an Issue:

- remove secrets, customer data, private domains, and private email addresses;
- include relevant software versions and a minimal reproduction;
- check root/admin server diagnostics for missing paths, services, sockets, extensions, or permissions;
- confirm that the problem is in ImagoPanel rather than an unsupported server or provider configuration.

Do not use public support channels for vulnerabilities. Follow [`SECURITY.md`](SECURITY.md).
