# ImagoPanel phpMyAdmin access adapter

This directory contains original ImagoPanel integration code licensed under the MIT License as an explicit exception to the repository-level AGPL-3.0 license. The bundled phpMyAdmin remains GPL-2.0-only and version 5.2.2.

`Adapter.php` is self-contained. It does not include or require ImagoPanel application PHP files and does not copy phpMyAdmin source. The adapter reads only:

- active user, domain, temporary-tool-access and selected-database fields from per-user JSON;
- a minimal non-secret runtime-settings JSON generated by the main application;
- short-lived one-time launch JSON generated by the main application;
- opaque adapter session JSON stored beneath the protected runtime state directory.

The bootstrap settings and phpMyAdmin launch files always live under `storage/domain-tool-state` inside the ImagoPanel installation. A customized user-data directory is passed as a non-secret runtime location, so the adapter does not need to load `config.php`.

Every access is bound to the request host and client IP. Temporary access is revalidated against the current active flag, time window, IP allowlist, phpMyAdmin permission, domain and database on every request. Missing, malformed, expired or changed state fails closed.

No ImagoPanel authentication/signing secret is transferred to phpMyAdmin. Database credentials are loaded server-side only after the requested database is authorized and are never written to launch, settings, cookie or adapter-session state.

The adapter uses PHP core cryptographic primitives (`random_bytes`, hashing, and password verification) and does not call either the native `sodium` extension or phpMyAdmin's bundled `sodium_compat` package.

The web server must deny direct HTTP access to this directory. The included `.htaccess` provides that protection when Apache overrides are enabled; deployments that disable overrides must add the equivalent rule to the global phpMyAdmin directory configuration.
